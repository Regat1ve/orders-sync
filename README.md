# orders-sync

Мини-синхронизатор заявок: забирает сырые заявки с `/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`, отбрасывает невалидные и схлопывает дубли по телефону. При дубле остаётся запись с максимальным `amount`, при равных суммах более поздняя по `created_at`.

- `GET /api/clients` отдаёт `{ clients, stats }`.
- Источник задаётся переменной окружения `ORDERS_URL`, по умолчанию `https://test.ooobs.ru/api/orders`.
- Идемпотентность: состояние не хранится, результат каждый раз считается заново из источника, поэтому повторный запуск не плодит дубли.

Запуск тестов: `node test.js` (без зависимостей, Node 18+).
